# Docs Folder

This folder contains higher-level writeups that support the labs.

## Files
- `architecture-note.md`
- `migration-plan.md`
- `troubleshooting-notes.md`
- `mock-interview-notes.md`

## Purpose
Store polished explanations that are longer than quick notes and more structured than raw lab output.

## Good Content
- architecture summaries
- migration approaches
- troubleshooting frameworks
- tradeoff writeups
- system design talk tracks

## Rule
This folder is for clarity, not for exhaustive detail.
Every doc should be readable in a few minutes.
