# Migration Lab

Prepare a platform migration scenario with risks, sequencing, and rollback thinking.

## Goal
Practice migration reasoning for a senior interview discussion.

## Files
- `migration-plan.md`
- `risks.md`
- `rollback-plan.md`

## Scope
Model a migration scenario such as:
- CI/CD migration
- cluster platform migration
- GitOps adoption
- policy and observability standardization

## What to Cover
- current state
- target state
- assumptions
- dependencies
- sequencing
- risks
- rollback
- success metrics

## What I Must Be Able to Explain
- why I would sequence the migration that way
- how I reduce blast radius
- how I keep delivery moving
- how I balance standardization with team adoption

## Deliverables
- concise migration plan
- risk log
- rollback strategy
- 5-minute talk track

## Completion Check
- I can explain the migration like a real project owner
- risks are concrete
- rollback is credible
- success metrics are measurable
