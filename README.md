# Platform Engineer Interview Labs

Hands-on repo for platform engineering interview prep focused on:
- Terraform
- AWS EKS
- Kubernetes networking
- Service mesh
- Helm
- GitHub Actions
- ArgoCD / GitOps
- Observability
- Policy as code
- Troubleshooting
- Migration design
- System design

## Repo Goal
Build interview-quality labs that I can:
1. implement
2. validate in terminal
3. explain clearly out loud
4. turn into concise interview answers

## Working Rules
- Terminal is the source of truth
- Cursor is used for scaffolding and editing
- I run the commands and debug manually
- End every lab with a short spoken explanation
- Capture weak points in `interview-notes.md`
- Compress final learnings into `final-cheat-sheet.md`

## Core Files

- `final-cheat-sheet.md` -> final summary
- `notes/` -> daily summaries, weak spots, flashcards
- `docs/` -> architecture, migration, and talk tracks

## Success Criteria
- I can explain EKS build order
- I can explain CNI vs Service vs Ingress vs Mesh
- I can explain CI vs GitOps clearly
- I can explain top observability signals
- I can explain policy tradeoffs
- I can debug common Kubernetes failures quickly
- I can speak to migration tradeoffs and platform design
