# System Design Lab

Design a platform architecture and defend the tradeoffs.

## Goal
Practice speaking about platform engineering as a coherent system, not isolated tools.

## Files
- `platform-design.md`
- `tradeoffs.md`
- `talk-track.md`

## Design Areas
- cluster strategy
- networking model
- CI and GitOps split
- secrets handling
- observability stack
- policy model
- upgrades and maintenance
- developer self-service
- multi-environment or multi-cluster approach

## What I Must Be Able to Explain
- why this architecture fits the use case
- where governance sits
- how reliability is maintained
- how developer experience is protected
- where complexity is justified
- what I would postpone for phase 2

## Deliverables
- architecture note
- tradeoff writeup
- 5-minute spoken talk track
- likely interviewer follow-up questions

## Completion Check
- I can describe the platform end to end
- I can defend tradeoffs, not just list components
- I can answer scale, governance, and upgrade questions
