# Notes Folder

This folder stores supporting notes for the weekend sprint.

## Files
- `saturday-summary.md`
- `sunday-summary.md`
- `weak-spots.md`
- `flashcards.md`
- `command-ref.md`

## Purpose
Capture:
- what I built
- what worked
- what failed
- what I still cannot explain cleanly
- what I should memorize

## Rule
Do not dump raw noise here.
Only keep:
- concise lessons
- repeated mistakes
- interview-quality talking points

## Recommended Format
For each note:
- Topic
- What I did
- What broke
- Fix
- Interview explanation
- Follow-up questions I should expect
